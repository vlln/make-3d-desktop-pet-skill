# 制作 3D 桌宠

从用户给定的阶段切入，并检查该阶段依赖的资产。记录目标运行时与 OS、支持的 VRM 版本与动作格式、设计参考、桌面显示尺寸以及交付需求。记录每次模型生成的服务、模型、参数、实际面数、素材来源和选择理由。沿用用户对生图、上传和付费的授权范围。已有获准的三视图与可编辑资产时，从本地诊断开始。下文 `$_S` 指技能目录。

已有模型穿模时，先用静止姿态、关闭弹簧的同一动作、开启弹簧的同一动作、运行时导入四组条件复现。依次排查几何间隙、关节权重、碰撞组和运行时差异。保留现有绑定，从副本修复最小问题区域。

## 1. 角色图与网格

读取 `$_S/references/image-and-mesh.md`。保留原始身份、比例和配件，优先复用一致的全身 T-Pose 参考。参考图无法直接建模时才考虑按模板生图或局部修图。上传前必须通过文档中的图像验收：对照批准原图检查头身比、身份和轮廓，核对各视角连接位置及姿势；局部缺陷修完复审，整体或身份漂移退回。只有需要独立运动、材质或装配验证的部件才拆分。

需要图转 3D 时，读取 `$_S/references/providers.md`：默认从 Tripo 智能拓扑起步，走现有官方 CLI、REST 或已授权 MCP，保留网页路径处理界面独占能力。提交前确认输入、视角、模型、次数和预算；保存 ID 再查询，不因超时重开任务。先验收灰模几何才生成正式贴图。用正、侧、背和斜视检查身份、身体高度、手指、关节布线、尾根和发束粘连。整片轮廓或结构偏差返工生成，单处问题局部修。输出包含纹理的 FBX 或 GLB 和转台对照。

## 2. Blender 网格、UV 与 VRM 骨架

读取 `$_S/references/blender.md`；Agent 用 Blender CLI + `bpy` 工作时先读 `$_S/references/blender-agent.md`，运行只读检查并保留对照，不能在后台可靠定位的操作交给人工界面。先在独立副本清理网格与贴图，再拟合 VRM Humanoid 骨架。正视和侧视对关节，细查手指，确认人形映射。第一次自动权重后立即导出测试 VRM，在目标软件中做加载和动作检查。若加载或动作失败，先修格式、朝向和骨骼映射。

## 3. 变形、弹簧骨和表情

读取 `$_S/references/rig-and-expressions.md`；脚本修改权重、Spring Bone 或 Expressions 时同时读 `$_S/references/blender-agent.md`。以待机、转头、抬臂、抬腿、弯指等实际动作定位坏权重。绑定大体正确时用选区遮罩，定点修复。自动权重普遍失败时评估按区域重绑。先让发尾随头部并可独立摆动，再配置 Spring Bone 和 Collider。用转身、拖动、回弹测试，而后制作和导出 Blink，测试转头同时眨眼及左右侧视。嘴型和更多表情按运行时事件需求补充。

## 4. 桌面实装

读取 `$_S/references/runtime.md`。在目标运行时加载最终模型和需要的动作，按使用场景试缩放、待机循环、弹簧碰撞、表情、拖拽和窗口行为。材质对照使用目标光照与实际桌宠尺寸。交付可编辑源文件、运行时模型与配套动作、生成设置及正侧背对照、实际桌面验证记录。把每项标为通过、失败或待测，注明实际测试的运行时与 OS。

先通过几何和动作验收，再精修观感。按角色尺度、实际显示尺寸和目标动作校准面数、碰撞半径与光照。
