# 生图、修图与生成网格

## A. 从设计稿得到可重建的输入

有用户认可的三视图时先核查是否已能直接使用。只从图版裁出各视图时，保持同一像素比例、地面基线和头顶线。确需重绘姿势时，将原稿作为身份参考直接提供给图像工具，另存为建模输入。约定头顶到下巴与全身高度的比值、腿长、主要色块、朝向和配件数量。多视图关节高度和姿势应一致，背部细节应来自参考或明确批准的补全。

### 从原图生成正面

> 使用附图的同一个角色。保留身份、头部与身体的相对比例、五官、发型、配色、服装结构和每件配饰的数量与位置。仅将角色摆成正面 T-Pose。双臂水平伸直，手掌朝下，手指保持清晰，腿自然分开。画出正交正视全身，头顶到脚底完整，左右留相同空间。让手、躯干和主要可动配件的轮廓分开，保留其真实连接位置。使用纯色背景、均匀照明、清楚的底色，无地面投影。输出单个角色的单张视图。

### 补背面或侧面

> 使用已通过的正面图与原画，输出同一角色、同一姿势的严格正交[背面/左侧]全身图。保持头顶、肩、手、胯、膝及脚底在同一高度。正面图里的衣服、配件、尾巴根部和发束走向在本视角中应连续。优先按原始背面或侧面设定补全可见区域。沿用原图背景、光照和占画布比例。

### 单处修图

> 基于这张已确认的 [视角] 图，仅修正 [部位和坐标范围]。将 [观察到的问题] 改为 [可比较的形态/位置/颜色]。保留区域外的像素与轮廓，保持画布、基线、人物大小、其余设定和姿势。输出一张完整图供叠图检查。

可用蒙版时圈到需改的部位并留少量过渡。编辑后将未授权区域从基线图合成回去，核对边缘、半透明区域、颜色和对位。身份与比例漂移时以基线重做局部。多视图涉及同一个部件时同步检查该部件的高度、朝向与连接点。裁图属于输入整理。将身体、头发、服装或配饰各自生成 3D 仅用于明确需要独立替换、变形或遮挡补全的部件。优先在合格网格中选连通块分件；独立生成时保留原三视图作母版，为每件保留同尺度裁图、遮罩和至少两个装配地标（例如发根与耳线、尾根与腰线）。不要把遮挡下的身体交给生成器随意重画；先用临时装配检查静态间隙及预期姿势，再投入修缝、贴图与绑骨。

### 图转 3D 前：审核每张原图或生成图

1. **锁定基准。** 保存用户认可的原图与各视角；标注头顶、下巴、肩、胯、膝、脚底和关键配件。明确哪些特征必须原样保留，哪些允许因姿态调整。没有同视角原图时不要凭像素叠图判断；按可见结构与已批准比例核对，无法确认的新增设计请用户复核。原图直接合格就不重绘。
2. **量比例并看身份。** 同视角先以脚底和人物总高等比对齐，禁止单独拉伸。头顶以头部主体为准，帽饰和高马尾单独标记。并排或半透明叠图，记录头高/总高、下巴至脚底/总高、腿长/总高及明显的轮廓差异；姿势不同只比较不受姿势影响的比例或用对应解剖地标。核对眼形、发型、服装轮廓、配件数量/位置、主要色块与标识。在无光影干扰处对照代表色；以用户批准图的容差为准，不设通用百分比。看起来更精细，不代表更忠于原设。
3. **核对多视图和可重建性。** 同尺度的正、侧、背图用水平线核对头、肩、胯、膝与脚底，同一发束、衣片、尾根或装饰在不同视角中应有一致的连接位置、遮挡次序和左右归属。必要时留空待补，不把互相矛盾的图混传。每张建模输入应是同一角色的完整单视图，目标肢体清楚、手与身体有间隙、运动部件不因阴影看似粘连，无截肢、额外手指、透视错位、背景杂物或重影。正交姿态符合后续绑定要求；面部和关键细节缩到桌宠尺寸仍应可读。
4. **做三态决定。** `通过，可建模`：身份与比例符合基准，所用视角一致且建模信息足够。`局部修正后复审`：仅一个边界、色块或局部标识有问题，用原始基准和遮罩修，比较区域外与其他视角。`退回`：头身比、身份、整体轮廓或关键连接漂移，或多视图互相矛盾；回到原图重新做对应视角，别在失败稿上连续重绘，别让 3D 工具替你猜。关键不确定项未解决前不上传。

留一张对照图或一行记录：`输入版本 / 视角 / 基准与比例差 / 身份与结构差 / 结论 / 下一步`。对照稿不作为建模输入。

## B. 生成网格并验收

1. **选视图和模式。** 单正面可先做草模。背部结构或侧面轮廓影响辨识时，加入通过一致性检查的对应视图。Tripo 优先选智能拓扑、可用的 P 系列和四边面模式。
2. **选最低通过档。** 默认先做一个 5k 或 10k 档候选；若档位都在预算内且差异值得对比，再跑第二档。只有手指分离、关节布线、嘴部/眼睑结构或关键配件不足时，再试 15k 或 20k。记录目标面数、实际多边形数和导出后的三角面数；这三者不可互换。四边面的优势是易于修改，不保证关节附近有适合弯折的走线。
3. **按缺陷范围修几何。** 单处坏形先试框选局部重塑，也可从候选移植合格部件并核对接缝与 UV。轮廓或遮挡关系整体不符时先修输入图。
4. **定几何再贴图。** 从 2K 开始。桌宠尺寸下仍有图案细节丢失时，对比 4K。叠加线框检查颜色溢出和接缝。
5. **导出后重载。** 用 FBX 的 Blender 预设或带贴图的 GLB，重载核对坐标、材质和纹理。

先用前、侧、背和关节近景对比每个额度内的候选，记录目标与实际面数和是否以四边面为主。把选布线的理由和贴图质量分开写。用灰模确认轮廓、对称性、手指分离、嘴部与眼睑是否可变形，检查长发与肩、尾根和裙摆是否粘连。只有低级别细节因像素尺寸消失时，优先选择通过的小面数版本。若手臂与躯干粘连或视角矛盾，先重新整理输入。
