# 权重、弹簧骨、碰撞与眨眼

先用同一组静止、转头、抬腿/臂、弯单指和待机姿势定位，再按下表或 `$_S/references/blender-agent.md` 执行。只修实际会触发的变形问题；不得用少测动作来掩盖明显断裂。

## 权重：局部修还是重绑

| 症状 | 判据与修法 |
|---|---|
| 转头时帽子、耳饰、短发留在原地 | 查头骨组未赋值或污染组。若该件应刚性随头，把目标顶点对头骨赋 1，去掉不相干变形骨影响。耳朵与脸/身连接时单独判断，不能整个头部盲刷。 |
| 抬腿时肌肤已经随腿、裤片却落后 | 对照相邻两层顶点的骨组，刚性同随区域匹配驱动，胯/膝的交界保留渐变。 |
| 鞋面被扯尖或邻指被带走 | 鞋本体检查脚骨/脚趾组及串入的小腿或对侧组，鞋口才留合理过渡；单指弯曲以该指独动验收，掌部允许正常过渡。 |
| 多个身体区域都错、局部修成本高 | 在副本比较分区重绑。大部件试体素，靠得很近的手指试热贴图；比较同一动作，而不是把体素或热贴图当成绝对更好。 |

**人工局部路径**：先选骨架，再选网格使网格活动，进 Weight Paint，按当前键位选择目标骨并旋转查错。Tool Settings → Options → Auto Normalize；Brush → Falloff 的 Sphere / Projected 决定近面衰减或贯穿影响，Front Faces Only 用于限制表面；实际刷前先验证遮罩和背面影响。编辑模式用 `L` 选帽子、耳饰或发束连通块，回 Weight Paint 启用面/顶点选择遮罩。红色是当前顶点组权重 1，不代表整体无串权。需要刚性精确赋值时用 Vertex Groups → Assign/Remove，不依赖反向笔刷恰好刷到 0。最后只平滑交界，关闭遮罩复测。骨架已拟合时可在 Viewport Display 从 Octahedral 换成 Stick；两只鞋重叠难辨时用 View → View Regions → Clipping Region（默认 `Alt+B`）暂时隔出一侧，裁剪不替代选区遮罩。镜像只在命名与网格对应成立时开，失败则单侧修，双侧单测。

**Auto-Rig Pro 是可选商业插件**，从[官方 Skinning 文档](https://www.lucky3d.fr/auto-rig-pro/doc/auto_rig.html)核对 Blender 兼容版本和选项。从本地已授权安装启动，别下载来路不明的改包。另存基线并解绑副本后：

1. 网格 Edit Mode 选双手顶点，反选得到身体；骨架 Pose Mode 选指链并反选得到身体骨骼。手腕交接根据实际网格划界，不把不可分的手臂整段误选。回 Object Mode 选网格再选骨架。
2. Auto-Rig Pro → Skin，用 Voxelized（默认类型/分辨率先试）并勾 Selected Vertices / Selected Bones Only，再 Bind。失败先查比例、重合点、断件和贴得过近的部位，再试 voxel 类型/分辨率；身体通过后验证手部仍未绑定（交接边界除外），保留此结果，两次分区 Bind 之间不要再 Unbind。
3. 改选手部顶点及对应手/指骨，Heat Maps、同样限制选区；确认不会覆盖身体已有组。复现单指、手腕与抬腿，查鞋的剩余变形；没有该插件就用 Blender 初绑、局部赋值/平滑或对应部件的权重传递，不盲目改拓扑重来。

## Spring Bone 与 Collider

1. **先决定是否值得做链。** 短而贴头的发型可只随头。相连的大团发束用一条主链，只有独立可动的发束才各开链；别为焊在一起的每根发丝强建链。核对尺度。已绑定角色不要孤立应用骨架缩放改变绑定，真要应用前后核对静止姿态与权重。
2. **沿中心线布骨。** 编辑模式可复制一根骨作为起点、由关节继续挤出；Volume 吸附和正侧/俯视复核。段数由要弯折的区域决定。手工可用 Armature → Names → Auto-Name Left/Right 后 Symmetrize；按角色自身左右核对 `.L`/`.R`，不要凭屏幕侧命名。选新链的根，再选头骨为活动骨，Edit Mode → Parent → Keep Offset；转头整个链应随行。
3. **只补新链蒙皮。** 既有绑定不能对全身再做一次 With Automatic Weights。确认现有 Armature Modifier 仍指向原骨架。需要自动分配时仅在副本和限定发片、限定新链的前提下用 Weight Paint → Weights → Assign Automatic from Bones；选区限制不可靠时手工/脚本定点赋值。头顶固定区保持随头，可动区减少头骨残留竞争，根部平滑过渡，耳饰留在正确组。先测试转头和手动转发骨分别正确，才装弹簧。
4. **Collider 不是 Spring。** 选骨架 → VRM → Spring Bone 1 → Colliders → `+`，选父骨（吸管需要时切 Pose Mode）；用局部偏移/radius 把球放到头部、胸、臂和手的真实接触区。空物体难辨时可开 In Front；单骨允许多个碰撞体用来补间隙。不是所有关节都要加。先建按侧的 Collider Group，头部可共享；切勿把模型左右和屏幕左右混用。
5. **Spring 单独引用链和组。** Springs → `+` → Joints，从根到梢逐关节加入，自动补子骨后也要核对顺序，选择相关 Collider Groups。启动可用固定根半径 0，活动节按发束宽度在模型尺度下估计；人体尺度可从 0.01 m 试起，不把它当全局常量。检查尾端 joint 不是额外自动延长的骨段。回弹初步可从刚度 1、重力强度 0、向下、Drag Force 0.5 试起，固定其他变量一次只调一项。
6. **区分穿过去和被顶出去。** 不碰撞时先查父骨、关节顺序、组关联及球覆盖，必要时补球/增半径；静置就弹开或发根被顶偏时先减关节半径或重新放碰撞球。开启扩展的动画预览，时间线归起始帧、播放，移动 root，正面/俯视看甩发与臂接触、停下后收敛。以同一姿势/动作分别测关闭与开启，再导入目标宿主复测。短发、尾巴、裙摆的驱动取舍相同，但碰撞组选实际会接触的身体骨段。

## Blink：贴图眼的人工路径

如果原模型已有可变形眼睑，直接做闭合形态键。贴图眼没有眼睑时才用眼片。先存原基色副本；所有要参与形态键的网格顶点和顺序须在建键前定好。

1. Add → Mesh → Plane，缩到单眼大小，Edit Mode → Subdivide 先试 4–5 cuts，Object → Apply → Scale。Modifiers → Deform → Shrinkwrap，目标脸部，Project，选实际朝向的投影轴与正/负方向，保留细小偏移并应用；左右对称时用 Mirror（需要时指定身体为镜像对象），非对称眼单独布置。斜视不能悬浮、刺出或被遮住。
2. 正视图 UV → Project from View，Shading 用 UV → Image Texture 接基色和 alpha（手工添加节点即可，不依赖 Node Wrangler），把 UV 岛对齐睁眼图案。Material → MToon → Alpha Mode: Mask，核对 alpha 来源、阈值和边缘。先用原眼作为对位基准，确认新眼后暂时隐藏眼片，在 Texture Paint 关不需要的镜像，遮罩内消掉原基色上画死的眼睛，再显示新眼检颜色和位置。
3. 在编辑模式把睁眼顶点复制为同一眼片网格中的另一个网格岛，独立材质，闭眼 UV 移到对应图案并赋给闭眼面。选 Basis 让睁眼在外、闭眼藏在脸内；Object Data → Shape Keys → `+` 建闭眼 key，显式把值设 1 后再编辑：闭眼露出、睁眼藏回。观察 0、1 与中间状态，正面和斜视排查穿出或双影；必要时调位移或使用宿主支持的二值表达式。VRM 渲染器不一定支持用可见性动画切网格。
4. VRM → Expressions → Blink → Morph Target Binds `+`，从 Outliner 选眼片网格、指定闭眼 key 与权重 1。给眼片确定的头骨驱动；通常用同一 Armature Modifier 和头骨权重 1，转头后检查眼片与脸没有相对位移。试着同时转头和 Blink，预览归 0 后导出新版本，再在运行时验证。眼睛停在世界原位先查绑定，不重做表情贴图；场景预览能眨眼、宿主不能时查 preset 名、绑定导出和宿主触发能力。

双眼 `blink` 先通过。左/右独立眨眼、开心或口型需要各自的形态或事件驱动，先问清宿主何时调用，再补并按事件验证。
